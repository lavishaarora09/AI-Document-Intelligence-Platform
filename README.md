AI Document Intelligence Platform

An AI-powered document analysis platform built with Python and Streamlit. It allows users to upload PDF documents, extract and analyze text, generate summaries, extract keywords, search inside documents, perform sentiment analysis, and generate reports.

Features
📄 PDF document upload and text extraction
📝 AI-powered document summarization
🔑 Keyword extraction
🔍 Search inside PDF documents
😊 Sentiment analysis
☁️ Word cloud generation
📊 Data visualization and document analytics
💬 AI document chatbot
🧠 Quiz generation
📑 Automated report generation
📥 Downloadable summaries and reports
📈 Interactive Streamlit dashboard

How to Run
Clone the repository:

git clone https://github.com/lavishaarora09/AI-Document-Intelligence-Platform.git

Open the project folder:

cd AI-Document-Intelligence-Platform

Install the required libraries:

pip install -r requirements.txt

Run the Streamlit application:

streamlit run app.py

The application will open at:

http://localhost:8501

The main purpose of this project is to make large PDF documents easier to understand and analyze using AI, NLP, and data-processing techniques.
